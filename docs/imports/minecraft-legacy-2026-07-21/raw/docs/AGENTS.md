# Docs Agent Rules

This folder inherits the workspace AI baseline from `C:\Codex\AGENTS.md` and
`C:\Codex\STANDARD.md`.

Documentation changes should be scoped, accurate, and linked to source files,
commands, or decisions when possible. Do not store secrets, tokens, PII,
customer data, raw production logs, private keys, or temporary sensitive
debugging output in docs.

Use `docs/ai/` only for durable, non-sensitive AI workflows, checklists,
playbooks, evals, and curated learnings.
