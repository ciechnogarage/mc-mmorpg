# level_1_moss_stalker learning

Status: durable local learning note
Date: 2026-07-07
Evidence source: `MCMMORPG/_validation/model_reviews/level_1_moss_stalker/iteration_log.md`

## Summary

This note records what a 5-iteration shell loop taught about repairing a grove-corruption predator quadruped without drifting into decorative rescue.

## Lessons

1. Family shell came before premium polish.
   - The model did not meaningfully improve until it first read as a low-long predator again.
   - Any attempt to jump straight into “premium” front polish before family repair would have produced fake quality.

2. Highest-yield repair order for this creature family was:
   1. chest/forequarter thrust
   2. hip/backline rhythm
   3. asymmetry/focal break
   4. planted-foot tension

3. Head narrowing alone had low leverage.
   - It reduced square-face symptoms a bit.
   - It did not solve the real problem while chest-head relationship was still wrong.

4. Side-read fixes produced larger gains than face polish.
   - Hip break and backline tension changed family readability more than early face tweaks.
   - For this mob, the side profile carried the truth of the family more than the front close-up did.

5. Asymmetry was only useful after the shell already read correctly.
   - Early asymmetry would have been decorative rescue.
   - Late asymmetry added character once structure and rhythm were already stable.

6. Stance tuning belonged at the end.
   - Front/rear foot logic improved the spring-loaded read.
   - Before shell and rhythm were stable, stance work would have optimized a broken baseline.

## Reusable rule

For predator quadrupeds in this project, do not start with texture/detail/asymmetry when the shell still fails. Repair order should be:

1. family shell
2. forequarter pressure
3. backline + hip rhythm
4. asymmetry / focal hierarchy
5. planted-foot tension

This note does not claim final approval for `level_1_moss_stalker`. It records the repair sequence and what produced real gains.
