# EqMigracja

Jednorazowa migracja akcesoriow MMOInventory 2.0 do slotow 9-14.
Uruchamia sie dwa ticki po kazdym wyborze profilu MMOProfiles.
Bez MMOProfiles uruchamia sie dwa ticki po wejsciu gracza.
Usuwa ikony `nexo:mmo_icon_*` i przedmioty typow EARRING, PAULDRONS, SHIRT.
Pozostale przedmioty przenosi do pasujacych slotow, plecaka lub upuszcza pod graczem.
Sloty CoreTools 8 i 18 pozostaja nietkniete; swiat `creator_limbo` jest pomijany.
Plugin mozna usunac, gdy wszystkie profile przeszly migracje.
